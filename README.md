Free REST API providing random dog images organized by breed and sub-breed from 120+ breeds. Backed by the Stanford Dogs Dataset and community-contributed photos, Dog CEO is widely used for learning HTTP concepts, API integration practice, and building dog-related applications. No authentication or API key is required. All endpoints return JSON with image URLs served via Vultr CDN. Open-source under the MIT license and community-funded via voluntary donations.

**APIs.json:** [https://raw.githubusercontent.com/api-evangelist/dog-ceo/refs/heads/main/apis.yml](https://raw.githubusercontent.com/api-evangelist/dog-ceo/refs/heads/main/apis.yml)

## APIs

### Dog CEO API

REST API for retrieving random and breed-specific dog images from a database of 20,000+ photos spanning 120+ breeds and sub-breeds. Supports random image selection, full breed listings, breed-specific image queries, and sub-breed queries. Returns JSON with CDN-hosted image URLs.

- **Human URL:** [https://dog.ceo/dog-api/](https://dog.ceo/dog-api/)
- **Base URL:** `https://dog.ceo/api`
